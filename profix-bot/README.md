# Бот-продавец PROFIX для Instagram Direct

Отвечает клиентам в директе, ведёт разговор до заявки, забирает номер
телефона и присылает готовый лид менеджеру.

Заменяет прежний `app.py` на сервере во Франкфурте (`/root/instagram-bot`).

## Чем отличается от прежнего бота

| | Было | Стало |
|---|---|---|
| Ответы | три заготовки на все случаи | разговор через Claude, знает все 13 позиций |
| Память | нет, каждое сообщение с нуля | помнит диалог сутки |
| Телефон | не ловил `+992...` и номера с пробелами | ловит все форматы |
| Заявки | никуда не уходили | карточка лида в Telegram или WhatsApp |
| Повторы | клиент получал дубли | защита по `mid` |

## Файлы

- `app.py` — весь бот: вебхук, разговор, лиды, отправка
- `catalog_data.py` — ассортимент. **Менять ассортимент только здесь**,
  в промпт он подставляется сам

## Переменные окружения

Уже настроены на сервере:

```
VERIFY_TOKEN          проверка вебхука
IG_ACCESS_TOKEN       токен Instagram (IGAAY...)
IG_APP_SECRET         секрет приложения Instagram
APP_SECRET            секрет приложения Meta
GRAPH_API_VERSION     v23.0
BOT_TOKEN             Telegram-бот для лидов
OWNER_IDS             кому слать лиды
```

Нужно добавить:

```
ANTHROPIC_API_KEY     ключ с console.anthropic.com — без него бот
                      отвечает заготовками и не умеет продавать
OUR_IG_ID             17841401291315898 — пока не выяснен верный
                      секрет подписи, служит запасной проверкой
```

Необязательные:

```
BOT_MODEL             по умолчанию claude-opus-5
PRICES                текстом: «Клей 800 — X сомони за мешок, ...».
                      Пусто — бот цен не называет и зовёт менеджера
LEAD_CHANNEL          telegram (по умолчанию) или whatsapp
WA_GATEWAY_URL        адрес шлюза WhatsApp
WA_GATEWAY_TOKEN      токен шлюза
WA_TO                 номер, куда слать заявки
STATE_FILE            где хранить диалоги, по умолчанию /app/data/dialogs.json
```

## Развёртывание

На сервере во Франкфурте:

```bash
cd /root/instagram-bot
cp app.py app.py.before-sales          # копия на случай отката
# скопировать сюда app.py и catalog_data.py из этой папки
echo "anthropic==0.69.0" >> requirements.txt
```

В `Dockerfile` добавить рядом с `COPY app.py .`:

```
COPY catalog_data.py .
```

В `docker-compose.yml` — том для памяти диалогов, иначе она пропадёт
при перезапуске:

```yaml
    volumes:
      - ./data:/app/data
```

Затем:

```bash
docker compose up -d --build
docker logs -f profix-instagram-bot
```

В `/health` появится `"brain": "claude"`, если ключ подхватился,
или `"fallback"`, если нет.

## Что осталось доделать

1. **Проверка подписи.** Верный секрет пока не найден: ни секрет
   Instagram, ни секрет Meta не сходятся с подписью в заголовке.
   Временно бот пропускает события по совпадению `OUR_IG_ID`.
   Это дыра: адрес вебхука может дёрнуть любой, кто его знает.
   Как выяснится секрет — убрать запасную проверку из `valid_signature`.

2. **Цены.** Пока не заданы, бот честно переводит на менеджера.

3. **WhatsApp.** Нужен шлюз (Green API, Wappi). Код готов, включается
   переменной `LEAD_CHANNEL=whatsapp`.
