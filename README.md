# powermix-site
Official website for PowerMix construction materials

## Line Design — финансы студии

В папке `finance/` — отдельное веб-приложение для внутреннего финансового
учёта дизайн-студии Line Design (проекты, клиенты, сотрудники, приходы, расходы, отчёты).
Серверная часть — в папке `server/`.

Запуск: `node server/server.js`, затем откройте `http://localhost:3000/finance/`.

Подробности: [finance/README.md](finance/README.md).
Размещение на сервере TimeWeb: [finance/deploy-timeweb.md](finance/deploy-timeweb.md).
