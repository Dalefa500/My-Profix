# Одиночные посты по макету заказчика (таджикский)

Формат 1080×1350. Макет повторяет слайд, который сделал сам заказчик:
логотип PROFIX + «Сифати беҳтарин» сверху, вопрос-заголовок, красная
черта, название продукта, короткая подпись, бейдж с весом, строка
применения; продукт справа без фона; снизу красная полоса
«Барои фармоиш ба Direct нависед».

**Названия продукции не переводятся на таджикский** — идут ровно как
на упаковке (по-русски): «Штукатурка гипсовая», «Плиточный клей 700»,
«Ровнитель для пола» и так далее. На таджикском — только заголовок-
вопрос и короткая строка применения снизу. Так клиент узнаёт товар
и на упаковке, и в переписке с ботом (та же логика зашита в самого
бота).

## Известный нюанс

- **`blue.jpg`** — фото мешка старой печати, сбоку у него написано
  «ШТУКАТУРКА ЦЕМЕНТНАЯ». Текст на слайде намеренно правильный —
  «Штукатурка гипсовая» (это гипсовая смесь, ошибка была только на
  старой упаковке). Пришлёте фото нового мешка с надписью «ШТУКАТУРКА
  ГИПСОВАЯ» на боку — заменю фото, текст менять не придётся.
