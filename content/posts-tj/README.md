# Одиночные посты по макету заказчика (таджикский)

Формат 1080×1350. Макет повторяет слайд, который сделал сам заказчик:
логотип PROFIX + «Сифати беҳтарин» сверху, вопрос-заголовок, красная черта,
название продукта, красная строка на таджикском, бейдж с весом, строка
применения; продукт справа без фона; снизу красная полоса
«Барои фармоиш ба Direct нависед».

Готово: `shpat.jpg` — шпатлёвка внутренняя, 25 кг (образец на согласование).

Тексты остальных продуктов заведены в `src/build_hero.py`, словарь `PRODUCTS`.

## Ресурсы

- `assets/bg1.png` — фон: интерьер, собран из съёмки красного мешка (мешок убран).
- `assets/logo_red.png` — логотип PROFIX, красный на прозрачном.
- Вырезанные продукты — `../carousel-tj/cutouts/*.png`.

## Сборка

```
cd src
python3 build_hero.py shpat      # без аргументов — все продукты
python3 shoot_hero.py            # рендер в hero_out/
```
