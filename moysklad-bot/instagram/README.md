# Бот Instagram Direct (аккаунт profix_dushanbe)

Отвечает клиентам в директе: рассказывает о смесях PowerMix, а про цены,
наличие и доставку зовёт менеджера и дублирует заявку в Telegram.

## Почему отдельный сервис, а не роут в веб-приложении

В `web/` живёт финансовое приложение: касса, обороты, долги. В директ
пишет кто угодно из интернета. Держать оба в одном процессе — значит
связать публичный обработчик с доступом к деньгам цеха. Поэтому здесь
свой контейнер, свой домен и ни одного импорта из `bot/` и `web/`:
токена МойСклад в этом сервисе просто нет.

## Что уже сделано

- `bot.profix.tj` указывает на сервер (проверено `ping`).
- Аккаунт `profix_dushanbe` — Professional, страница Facebook «Profix
  Душанбе» привязана. Это главное предусловие Meta, оно выполнено.

## Шаг 1. Приложение в консоли Meta

1. [developers.facebook.com](https://developers.facebook.com) → **My Apps**
   → **Create App** → тип **Business**.
2. В приложение добавьте продукт **Instagram** → **Instagram API setup
   with Instagram login**.
3. Подключите аккаунт `profix_dushanbe`.
4. Запросите права: `instagram_business_basic` и
   `instagram_business_manage_messages`.
5. Сгенерируйте долгоживущий токен — это `IG_ACCESS_TOKEN`.
6. **Settings → Basic → App Secret** — это `IG_APP_SECRET`.

Если подключаетесь через Facebook Login, а не Instagram Login: права
называются `instagram_manage_messages` + `pages_manage_metadata`, в
`.env` заполните `IG_PAGE_ID` и поменяйте `IG_GRAPH_BASE` на
`https://graph.facebook.com`.

## Шаг 2. Вебхук

1. В приложении → **Webhooks** → подписка на объект **Instagram**.
2. **Callback URL:** `https://bot.profix.tj/webhook`
3. **Verify token:** та же строка, что в `IG_VERIFY_TOKEN` в `.env`.
4. Подпишитесь на поле **`messages`**.

Сервис должен быть уже запущен, иначе проверку адреса пройти нечем:
Meta дёргает `GET /webhook` и ждёт обратно `hub.challenge`.

## Шаг 3. Запуск

```bash
cd moysklad-bot
# впишите в .env: BOT_DOMAIN, IG_VERIFY_TOKEN, IG_APP_SECRET, IG_ACCESS_TOKEN
docker compose up -d --build
docker compose logs -f instagram
```

В логах при старте должно быть: `Instagram-бот запущен`.

Проверка живости: `curl https://bot.profix.tj/health` → `{"status":"ok"}`.

## Шаг 4. App Review — без него бот увидят только тестировщики

Пока приложение в режиме разработки, бот отвечает **только тем, у кого
есть роль в приложении** (админ, разработчик, тестировщик). Обычный
клиент напишет — и не получит ничего, при этом в логах не будет ошибок.
Это штатное поведение Meta, а не поломка.

Чтобы бот заработал для всех, отправьте приложение на **App Review** с
правами на переписку. Проверка занимает несколько дней: Meta смотрит
видеозапись работы бота и описание, зачем вам доступ к сообщениям.

Добавить себя тестировщиком для проверки до ревью: **App Roles → Roles →
Add People → Instagram Tester**, затем принять приглашение в Instagram →
Настройки → Для профессионалов → Приложения и сайты.

## Правило 24 часов

Отвечать можно в течение суток после сообщения клиента. Позже Meta
отклонит отправку — в логах будет ошибка от Graph API. Это ограничение
платформы; такие диалоги дожимает живой менеджер.

## Режимы ответа

| Что в `.env` | Как отвечает |
|---|---|
| `AISA_API_KEY` задан | Claude через AIsa (`api.aisa.one`), живым текстом, с каталогом в промпте |
| `ANTHROPIC_API_KEY` задан, `AISA_API_KEY` пуст | тот же Claude, напрямую у Anthropic |
| ключей нет | правила по ключевым словам — беднее, зато бесплатно |

Какой путь выбран, видно в логах при старте: `Claude: через AIsa`,
`напрямую у Anthropic` или `нет, работают правила`.

В обоих режимах бот **никогда не называет цены**: они меняются, а ошибка
в переписке дороже паузы. Цены — всегда через менеджера.

Каталог лежит в `catalog.py` и повторяет сайт. Добавили смесь на сайт —
добавьте и туда.

## Когда что-то не работает

| Симптом | Где искать |
|---|---|
| Meta не сохраняет вебхук | сервис не запущен, или `IG_VERIFY_TOKEN` в `.env` и в консоли различаются |
| в логах `Отклонён запрос с неверной подписью` | `IG_APP_SECRET` не тот |
| в логах `Graph API отказал` | смотрите тело ответа рядом: истёк токен, не выданы права или закрылось окно 24 часов |
| бот молчит на сообщения посторонних | не пройден App Review (см. шаг 4) |
| бот отвечает сам себе | не должно случаться — эхо отбрасывается по `is_echo` |
