1. О сервисе

PROFIX — производство сухих строительных смесей и готовых составов, Душанбе, Таджикистан. Мы используем автоматического помощника, который отвечает на сообщения клиентов в Instagram Direct.

2. Какие данные обрабатываются

При получении сообщения обрабатываются идентификатор отправителя в Instagram, текст сообщения и, если клиент сам его указал, номер телефона. Другие данные мы не собираем.

3. Зачем

Только чтобы ответить на обращение и передать заявку менеджеру, который свяжется с клиентом. Для рекламы и рассылок эти данные не используются.

4. Передача третьим лицам

Мы не продаём и не передаём данные третьим лицам. Для формирования ответов используется сервис Anthropic (Claude); туда попадает только текст переписки, без иных персональных сведений.

5. Хранение

Переписка остаётся в Instagram и подчиняется правилам Meta. На нашем сервере история диалога хранится не дольше суток и затем удаляется автоматически. Технические журналы перезаписываются.

6. Удаление данных

Запросить удаление можно в любой момент — порядок описан на странице Удаление данных.
